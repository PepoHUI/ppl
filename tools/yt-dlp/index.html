yt-dlp

Конструктор команды для yt-dlp — ссылка, качество (mp4), папка и фрагмент без запоминания флагов

Команда
Как пользоваться
  1. 1. Установить yt-dlp и ffmpeg
  2. 2. Открыть консоль

  3. 3. Вставить команду

    Скопируйте команду выше и вставьте в консоль, затем нажмите Enter.

  4. 4. Что заполнять в форме

    Вставьте ссылку на видео, выберите нужное качество и папку для сохранения — папка запоминается и подставится при следующих запросах. При необходимости включите «Скачать только фрагмент» и укажите промежуток (с — по), чтобы скачать часть видео, а не целиком.
